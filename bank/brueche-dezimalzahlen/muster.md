# Musterbeispiele: brueche-dezimalzahlen

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Anteil bestimmen

Aufgabe: Der Streifen ist in gleich große Teile geteilt. Welcher
Anteil des Streifens ist gefärbt? Grafik: `\bruchrechteck{3}{7}`

| Schritt | Zeile |
|---|---|
| alle Teile zählen | $7$ gleich große Teile, das ist der Nenner |
| gefärbte Teile zählen | $3$ Teile gefärbt, das ist der Zähler |
| Bruch schreiben | $3$ von $7$ Teilen: $\frac{3}{7}$ |
| Ergebnis | $\frac{3}{7}$ |

## e1 k2 Bruchteil einer Größe

Aufgabe: Berechne $\frac{1}{7}$ von $63$.

| Schritt | Zeile |
|---|---|
| das Ganze nennen | das Ganze sind $63$ |
| durch den Nenner teilen | $63 : 7 = 9$ |
| Ergebnis | $9$ |

## e2 k1 Kürzen und Erweitern

Aufgabe: Erweitere $\frac{4}{7}$ mit $3$.

| Schritt | Zeile |
|---|---|
| Zähler mal 3 | $4 \cdot 3 = 12$ |
| Nenner mal 3 | $7 \cdot 3 = 21$ |
| Bruch schreiben | $\frac{4}{7} = \frac{12}{21}$ |
| Ergebnis | $\frac{12}{21}$ |

## e3 k1 Vergleichen

Aufgabe: Welcher Bruch ist größer: $\frac{5}{13}$ oder
$\frac{8}{13}$?

| Schritt | Zeile |
|---|---|
| Nenner vergleichen | beide haben den Nenner $13$ |
| Zähler vergleichen | $8 > 5$ |
| Zeichen setzen | $\frac{8}{13} > \frac{5}{13}$ |
| Ergebnis | $\frac{8}{13}$ |

## e4 k1 Umwandeln

Aufgabe: Schreibe $\frac{62}{100}$ als Dezimalzahl.

| Schritt | Zeile |
|---|---|
| Nenner ansehen | Hundertstel: zwei Stellen nach dem Komma |
| Zähler eintragen | $62$ Hundertstel: $6$ Zehntel, $2$ Hundertstel |
| Dezimalzahl schreiben | $\frac{62}{100} = 0{,}62$ |
| Ergebnis | $0{,}62$ |

## e5 k2 Vergleichen und Ordnen

Aufgabe: Welche Zahl ist größer: $0{,}83$ oder $0{,}87$?

| Schritt | Zeile |
|---|---|
| Einer vergleichen | beide $0$ |
| Zehntel vergleichen | beide $8$ |
| Hundertstel vergleichen | $7 > 3$ |
| Zeichen setzen | $0{,}87 > 0{,}83$ |
| Ergebnis | $0{,}87$ |
