# Musterbeispiele: kurvenuntersuchung

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Monotonie

Aufgabe: Gegeben ist die Ableitung $f'(x) = 3x - 9$. Bestimme das
Vorzeichen von $f'(x)$ auf dem Intervall $[1; 2]$. Steigt oder fällt
$f$ dort?

| Schritt | Zeile |
|---|---|
| linken Rand einsetzen | $f'(1) = 3 \cdot 1 - 9 = -6$ |
| rechten Rand einsetzen | $f'(2) = 3 \cdot 2 - 9 = -3$ |
| Vorzeichen | $f'$ ist eine steigende Gerade, dazwischen liegt $f'(x)$ zwischen $-6$ und $-3$: negativ |
| Ergebnis | $f$ fällt auf $[1; 2]$ |

## e2 k1 Extrempunkte berechnen

Aufgabe: Berechne die Stellen, an denen der Graph von
$f(x) = x^3 - 3x^2 - 24x$ eine waagerechte Tangente hat.

| Schritt | Zeile |
|---|---|
| Ableitung bilden | $f'(x) = 3x^2 - 6x - 24$ |
| Bedingung $f'(x) = 0$ | $3x^2 - 6x - 24 = 0$ |
| durch 3 teilen | $x^2 - 2x - 8 = 0$ |
| Lösungsformel | $x = 1 \pm \sqrt{1 + 8} = 1 \pm 3$ |
| Ergebnis | $x_1 = 4$; $x_2 = -2$ |

## e2 k2 Extrempunkte nachweisen

Aufgabe: Zeige, dass $f'(3) = 0$ gilt, der Graph von
$f(x) = x^3 - 6x^2 + 9x$ also bei $x = 3$ eine waagerechte Tangente
hat.

| Schritt | Zeile |
|---|---|
| Ableitung bilden | $f'(x) = 3x^2 - 12x + 9$ |
| Stelle einsetzen | $f'(3) = 3 \cdot 9 - 12 \cdot 3 + 9$ |
| ausrechnen | $f'(3) = 27 - 36 + 9 = 0$ |
| Ergebnis | $f'(3) = 0$, die Tangente bei $x = 3$ ist waagerecht |

## e3 k2 Wendepunkte und Krümmung

Aufgabe: Bilde die erste, zweite und dritte Ableitung von
$f(x) = 2x^3 - 6x^2 + x$.

| Schritt | Zeile |
|---|---|
| erste Ableitung | $f'(x) = 6x^2 - 12x + 1$ |
| zweite Ableitung | $f''(x) = 12x - 12$ |
| dritte Ableitung | $f'''(x) = 12$ |
| Ergebnis | $f'(x) = 6x^2 - 12x + 1$; $f''(x) = 12x - 12$; $f'''(x) = 12$ |

## e4 k1 Graph und Ableitungsgraph

Aufgabe: Die Abbildung zeigt den Graphen von $f$, eine nach unten
geöffnete Parabel mit dem Hochpunkt $H(3 | 4{,}5)$. Gib die
Nullstellen von $f'$ an und trage das Vorzeichen von $f'$ in jedem
Abschnitt ein.

| Schritt | Zeile |
|---|---|
| waagerechte Tangente suchen | nur im Hochpunkt, bei $x = 3$ |
| Nullstelle von $f'$ | $x = 3$ |
| links davon | der Graph steigt, also $f' > 0$ für $x < 3$ |
| rechts davon | der Graph fällt, also $f' < 0$ für $x > 3$ |
| Ergebnis | Nullstelle $x = 3$; $f'$: plus, dann minus |

## e5 k1 Sachzusammenhang

Aufgabe: Eine Suppe wird in einen Raum mit $20$ °C gestellt. Die
Abbildung zeigt ihre Temperatur (in °C) $t$ Minuten danach, beginnend
bei $80$ °C. Beschreibe den Verlauf im Sachzusammenhang.

| Schritt | Zeile |
|---|---|
| Anfangswert | bei $t = 0$: $80$ °C |
| Richtung | der Graph fällt überall: die Suppe kühlt ab |
| Tempo | erst steil, dann immer flacher: sie kühlt immer langsamer ab |
| Grenze | der Graph nähert sich $20$ °C, der Raumtemperatur |
| Ergebnis | Die Temperatur fällt von $80$ °C erst schnell, dann langsamer und nähert sich $20$ °C. |
