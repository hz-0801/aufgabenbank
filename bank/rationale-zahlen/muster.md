# Musterbeispiele: rationale-zahlen

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Ordnen

Aufgabe: Trage die Zahlen $-3$ und $2$ an der Zahlengeraden ein.
Grafik: `\zahlenstrahl[xmin=-10,xmax=10,xstep=1]{}`

| Schritt | Zeile |
|---|---|
| Null finden | die Null ist die Mitte, links negativ, rechts positiv |
| negative Zahl | $-3$: von der Null $3$ Striche nach links |
| positive Zahl | $2$: von der Null $2$ Striche nach rechts |
| Ergebnis | von links: $-3$; $2$ |

## e2 k3 Addieren/Subtrahieren

Aufgabe: Berechne $-4 + 6$.

| Schritt | Zeile |
|---|---|
| Start | Start bei $-4$ |
| Pfeil | plus $6$: $6$ nach rechts |
| ablesen | $-4 + 6 = 2$ |
| Ergebnis | $2$ |

## e3 k1 Multiplizieren/Dividieren

Aufgabe: Berechne $4 \cdot (-7)$.

| Schritt | Zeile |
|---|---|
| Vorzeichen | verschiedene Vorzeichen, also minus |
| Betrag | $4 \cdot 7 = 28$ |
| zusammensetzen | $4 \cdot (-7) = -28$ |
| Ergebnis | $-28$ |

## e4 k1 Terme und Sachaufgaben

Aufgabe: Ein Konto steht bei $-30$ €. Dann werden $45$ € eingezahlt.
Wie hoch ist der neue Kontostand?

| Schritt | Zeile |
|---|---|
| Startwert | $-30$ € |
| Änderung | eingezahlt: $+45$ € |
| rechnen | $-30 + 45 = 15$ |
| Ergebnis | $15$ € |
