# Musterbeispiele: stammfunktion-und-hauptsatz

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Stammfunktion

Aufgabe: $f(x) = 36 - (6 - x)^2$ – eine Stammfunktion $F$?

| Schritt | Zeile |
|---|---|
| Klammer ausmultiplizieren | $f(x) = 36 - (36 - 12x + x^2)$ |
| zusammenfassen | $f(x) = 12x - x^2$ |
| gliedweise aufleiten | $F(x) = 12 \cdot \frac{1}{2}x^2 - \frac{1}{3}x^3$ |
| Ergebnis | $F(x) = 6x^2 - \frac{1}{3}x^3$ |

## e2 k1 Hauptsatz

Aufgabe: Wert des Integrals von $-1$ bis $2$ über $f(x) = 3x^2 + 8x$?

| Schritt | Zeile |
|---|---|
| Stammfunktion bilden | $F(x) = x^3 + 4x^2$ |
| Klammer | $\left[x^3 + 4x^2\right]_{-1}^{2}$ |
| obere Grenze einsetzen | $F(2) = 8 + 16 = 24$ |
| untere Grenze einsetzen | $F(-1) = -1 + 4 = 3$ |
| abziehen | $F(2) - F(-1) = 24 - 3$ |
| Ergebnis | $21$ |

## e3 k1 Der Graphenblick

Aufgabe: Der Graph von $f(x) = \frac{1}{2}(x - 1)^2 - 8$ ist gegeben.
Skizziere die Stammfunktion $F$ durch $P(0 | 1)$.

| Schritt | Zeile |
|---|---|
| Nullstellen von $f$ | $x = -3$ und $x = 5$ |
| Vorzeichen von $f$ | plus, minus, plus |
| Extremstellen von $F$ | Hochpunkt bei $x = -3$, Tiefpunkt bei $x = 5$ |
| Wendestelle von $F$ | $x = 1$, wo $f$ seinen Tiefpunkt hat |
| durch den Punkt legen | $F$ fällt bei $x = 0$ und geht durch $P(0 \| 1)$ |
| Ergebnis | $F$ steigt bis $-3$, fällt bis $5$, steigt dann wieder |

## e4 k1 Integralfunktion

Aufgabe: $J(x)$ ist das Integral von $4$ bis $x$ über
$f(t) = t^2 - 2t$ – eine Nullstelle von $J$ und $J'$?

| Schritt | Zeile |
|---|---|
| untere Grenze | $J(4) = 0$, gleiche Grenzen |
| Nullstelle | $x = 4$ |
| Ableitung ist der Integrand | $J'(x) = x^2 - 2x$ |
| Ergebnis | Nullstelle $x = 4$; $J'(x) = x^2 - 2x$ |
