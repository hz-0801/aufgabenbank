# Musterbeispiele: binomische-formeln

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Summe mal Summe

Aufgabe: Fasse zusammen: $3a + 2b + 5a + 4b$

| Schritt | Zeile |
|---|---|
| ordnen | $3a + 5a + 2b + 4b$ |
| zusammenfassen | $= 8a + 6b$ |
| Ergebnis | $8a + 6b$ |

## e2 k2 Binomische Formeln

Aufgabe: Multipliziere aus: $(x + 7)^2$

| Schritt | Zeile |
|---|---|
| a und b bestimmen | $a = x$, $b = 7$ |
| erste Formel einsetzen | $x^2 + 2 \cdot x \cdot 7 + 7^2$ |
| ausrechnen | $= x^2 + 14x + 49$ |
| Ergebnis | $x^2 + 14x + 49$ |

## e3 k1 Faktorisieren

Aufgabe: Faktorisiere: $x^2 - 49$

| Schritt | Zeile |
|---|---|
| Quadrate erkennen | $x^2 = x^2$ und $49 = 7^2$ |
| dritte Formel rückwärts | $x^2 - 7^2 = (x + 7) \cdot (x - 7)$ |
| Probe | $(x + 7) \cdot (x - 7) = x^2 - 49$ |
| Ergebnis | $(x + 7) \cdot (x - 7)$ |
