# Musterbeispiele: lineare-gleichungen

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k2 Lösung prüfen

Aufgabe: Prüfe, ob $9$ die Gleichung $x + 6 = 15$ löst.

| Schritt | Zeile |
|---|---|
| einsetzen | $9 + 6$ |
| ausrechnen | $9 + 6 = 15$ |
| vergleichen | links $15$, rechts $15$: beide gleich |
| Ergebnis | $9$ ist Lösung (wA) |

## e1 k3 Durch Probieren lösen

Aufgabe: Rechne mit der Tabelle aus, für welches $x$ die Gleichung
$2x + 5 = 19$ stimmt. Die Tabelle hat die Werte $x = 5, 6, 7, 8$.

| Schritt | Zeile |
|---|---|
| einsetzen $x = 5$ | $2 \cdot 5 + 5 = 15$ |
| einsetzen $x = 6$ | $2 \cdot 6 + 5 = 17$ |
| einsetzen $x = 7$ | $2 \cdot 7 + 5 = 19$ |
| vergleichen | bei $x = 7$ steht $19$ wie rechts |
| Ergebnis | $x = 7$ |

## e2 k3 Umformen

Aufgabe: Löse die Gleichung. $x + 7 = 16$

| Schritt | Zeile |
|---|---|
| Umformung anschreiben | $x + 7 = 16 \mid -7$ |
| minus 7 auf beiden Seiten | $x + 7 - 7 = 16 - 7$ |
| ausrechnen | $x = 9$ |
| Ergebnis | $x = 9$ |

## e3 k2 x beidseitig

Aufgabe: Löse die Gleichung. $6x = 4x + 14$

| Schritt | Zeile |
|---|---|
| Seite mit weniger x finden | rechts steht $4x$ |
| minus 4x auf beiden Seiten | $6x - 4x = 4x + 14 - 4x$ |
| zusammenfassen | $2x = 14$ |
| geteilt durch 2 | $x = 7$ |
| Ergebnis | $x = 7$ |

## e4 k1 Aufstellen

Aufgabe: Der Satz heißt: „Eine Zahl minus 8 ergibt 15.“ $x$ ist die
gesuchte Zahl. Kreuze an, welche Gleichung passt:
$8x = 15$ · $x - 8 = 15$ · $8 - x = 15$

| Schritt | Zeile |
|---|---|
| Unbekannte festlegen | $x$ ist die gesuchte Zahl |
| Text übersetzen | „eine Zahl minus 8“: $x - 8$ |
| Gleichung | „ergibt 15“: $x - 8 = 15$ |
| vergleichen | $8x$ ist mal, $8 - x$ zieht falsch herum ab |
| Ergebnis | $x - 8 = 15$ |
