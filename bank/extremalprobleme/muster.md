# Musterbeispiele: extremalprobleme

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Figur und Term

Aufgabe: Der Punkt $P(2 | f(2))$ auf dem Graphen von
$f(x) = 20 - x^2$ ist eine Ecke eines Rechtecks; die
gegenüberliegende Ecke liegt im Ursprung, die Seiten liegen auf den
Achsen. Gib Breite und Höhe des Rechtecks an.

| Schritt | Zeile |
|---|---|
| Breite ablesen | die Stelle $2$ |
| Höhe als Funktionswert | $f(2) = 20 - 2^2$ |
| ausrechnen | $f(2) = 20 - 4 = 16$ |
| Ergebnis | Breite $2$, Höhe $16$ |

## e2 k1 Zielfunktion aufstellen

Aufgabe: An einer Hauswand wird ein rechteckiger Sitzplatz an den
drei übrigen Seiten mit $26$ m Randsteinen eingefasst; $a$ steht
senkrecht zur Wand, $b$ parallel. Die Fläche soll möglichst groß
werden. Notiere Haupt- und Nebenbedingung und stelle die
Nebenbedingung nach $b$ um.

| Schritt | Zeile |
|---|---|
| Hauptbedingung | $A = a \cdot b$ |
| Nebenbedingung | $2a + b = 26$ |
| nach $b$ umstellen | $b = 26 - 2a$ |
| Ergebnis | $A = a \cdot b$ mit $b = 26 - 2a$ |

## e3 k1 Maximum bestimmen

Aufgabe: Die Zielfunktion $A(x) = 147x - x^3$, $0 < x < \sqrt{147}$,
beschreibt einen Flächeninhalt. Bestimme die Stelle mit $A'(x) = 0$
im Definitionsbereich.

| Schritt | Zeile |
|---|---|
| Ableitung bilden | $A'(x) = 147 - 3x^2$ |
| Bedingung $A'(x) = 0$ | $147 - 3x^2 = 0$ |
| umstellen | $x^2 = 49$ |
| Lösungen | $x = 7$ oder $x = -7$ |
| im Definitionsbereich wählen | $x = -7$ entfällt |
| Ergebnis | $x = 7$ |
