# Musterbeispiele: pythagoras

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen, nicht aus dem Merkkasten).
Reine Daten; die Form auf dem Blatt setzt der Zusammenbau
(layout-befunde 55).

## e1 k2 Hypotenuse

Aufgabe: In einem rechtwinkligen Dreieck sind die Katheten
$a = 65$ cm und $b = 72$ cm lang. Berechne die Länge der
Hypotenuse $c$.

| Schritt | Zeile |
|---|---|
| Gleichung | $c^2 = 65^2 + 72^2$ |
| Quadrate | $c^2 = 4\,225 + 5\,184$ |
| Zwischenergebnis | $c^2 = 9\,409$ |
| Wurzel | $c = \sqrt{9\,409} = 97$ cm |
| Ergebnis | $c = 97$ cm |

## e2 k3 Kathete

Aufgabe: In einem rechtwinkligen Dreieck ist die Hypotenuse
$c = 113$ cm lang. Eine Kathete ist $b = 15$ cm lang. Berechne die
Länge der Kathete $a$.

| Schritt | Zeile |
|---|---|
| Gleichung umstellen | $a^2 = 113^2 - 15^2$ |
| Quadrate | $a^2 = 12\,769 - 225$ |
| Zwischenergebnis | $a^2 = 12\,544$ |
| Wurzel | $a = \sqrt{12\,544} = 112$ cm |
| Ergebnis | $a = 112$ cm |

## e3 k2 Figuren und Körper

Aufgabe: Die Figur zeigt ein gleichschenkliges Dreieck. Die
Grundseite ist $48$ cm lang, die Schenkel sind je $26$ cm lang.
Berechne die Höhe $h$.

| Schritt | Zeile |
|---|---|
| halbe Grundseite | $\frac{48}{2} = 24$ cm |
| Gleichung umstellen | $h^2 = 26^2 - 24^2$ |
| Quadrate | $h^2 = 676 - 576$ |
| Zwischenergebnis | $h^2 = 100$ |
| Wurzel | $h = \sqrt{100} = 10$ cm |
| Ergebnis | $h = 10$ cm |
