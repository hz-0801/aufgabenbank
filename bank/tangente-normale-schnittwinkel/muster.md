# Musterbeispiele: tangente-normale-schnittwinkel

Je Verfahrenskette ein vorgerechnetes Beispiel am Grundfall, mit
eigenen Zahlen (nicht aus dem Päckchen). Reine Daten; die Form auf
dem Blatt setzt der Zusammenbau (layout-befunde 55).

## e1 k1 Tangentengleichung

Aufgabe: Gegeben ist $f(x) = x^3 - 4x + 1$. Bestimme die Gleichung
der Tangente an den Graphen von $f$ im Punkt $P(2 | f(2))$.

| Schritt | Zeile |
|---|---|
| Funktionswert | $f(2) = 8 - 8 + 1 = 1$ |
| Ableitung bilden | $f'(x) = 3x^2 - 4$ |
| Anstieg | $m = f'(2) = 12 - 4 = 8$ |
| n aus P | $1 = 8 \cdot 2 + n$ |
| nach n auflösen | $n = 1 - 16 = -15$ |
| Ergebnis | $t(x) = 8x - 15$ |

## e2 k1 Berührung nachweisen

Aufgabe: Ist $g(x) = 5x - 4$ Tangente an den Graphen von
$f(x) = x^3 + 2x - 2$ an der Stelle $x = 1$?

| Schritt | Zeile |
|---|---|
| Bedingung Funktionswert | $f(1) = 1 + 2 - 2 = 1$, $g(1) = 5 - 4 = 1$ |
| Ableitung bilden | $f'(x) = 3x^2 + 2$ |
| Bedingung Steigung | $f'(1) = 5$ = Steigung von $g$ |
| Ergebnis | Ja; beide Bedingungen erfüllt, $g$ ist Tangente |

## e3 k1 Normale

Aufgabe: Die Tangente an den Graphen von $f$ im Punkt $P(2 | 5)$
hat die Steigung $4$. Bestimme die Gleichung der Normalen in $P$.

| Schritt | Zeile |
|---|---|
| Normalensteigung | $m_n = -\frac{1}{4} = -0{,}25$ |
| b aus P | $5 = -0{,}25 \cdot 2 + b$ |
| nach b auflösen | $b = 5 + 0{,}5 = 5{,}5$ |
| Ergebnis | $n(x) = -0{,}25x + 5{,}5$ |

## e4 k1 Winkel

Aufgabe: Eine Gerade hat die Steigung $-1{,}5$. Berechne ihren
Steigungswinkel gegen die positive $x$-Richtung.

| Schritt | Zeile |
|---|---|
| Ansatz | $\mathrm{tan}\,\alpha = -1{,}5$ |
| Arkustangens (Grad-Modus) | $\mathrm{tan}^{-1}(-1{,}5) \approx -56{,}3^\circ$ |
| Lage | die Gerade fällt, der Steigungswinkel ist stumpf |
| stumpfer Winkel | $\alpha = 180^\circ - 56{,}3^\circ$ |
| Ergebnis | $\alpha \approx 123{,}7^\circ$ |

## e5 k1 Dreiecke und Figuren

Aufgabe: Die Gerade $g(x) = -\frac{2}{5}x + 4$ schließt mit den
Koordinatenachsen ein Dreieck ein. Berechne seinen Flächeninhalt.

| Schritt | Zeile |
|---|---|
| Nullstelle | $0 = -\frac{2}{5}x + 4$, also $x = 10$ |
| y-Achsenabschnitt | $g(0) = 4$ |
| Katheten | $10$ und $4$ |
| Fläche | $A = \frac{1}{2} \cdot 10 \cdot 4$ |
| Ergebnis | $A = 20$ |
