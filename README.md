# aufgabenbank
Aufgabenbank je Sprosse des Themenkatalogs (mathe-nachhilfe), Berlin-Brandenburg

Die Bank hält je Sprosse eines Katalogeintrags geprüfte Aufgaben
mit Lösung, als JSONL unter `bank/<eintrag>/`. Blätter entstehen
später durch Auswahl aus der Bank, nicht durch Erzeugung; die
Struktur kommt allein aus dem Katalog. Form, Felder, Mengen und
Regeln stehen in `bank.md`; `werkzeuge/bank-pruef.py` rechnet jede
Lösung nach.
